# Blockly для ESP32 в Docker

Визуальный редактор программ на основе Google Blockly, адаптированный для генерации кода Arduino C++ для микроконтроллеров ESP32.

## Быстрый старт

1. **Соберите образ**  
   `docker build -t esp32-blockly .`

2. **Запустите контейнер**  
   `docker run -d -p 8080:80 esp32-blockly`

3. Откройте в браузере `http://localhost:8080`

## Использование

- Перетаскивайте блоки из панели слева в рабочую область.
- Соединяйте блоки для создания алгоритма.
- Нажмите **«Сгенерировать код»** – в нижней панели появится код на C++.
- Скопируйте код в Arduino IDE или PlatformIO и загрузите на ESP32.

## Доступные блоки

- **Ввод/вывод**: настройка режима пина, цифровое чтение/запись.
- **Время**: задержка в миллисекундах.
- **Serial**: инициализация UART, вывод текста.

## Расширение

Вы можете легко добавить новые блоки, отредактировав `blocks.js` и `generators.js`, а также дополнив `toolbox` в `index.html`.
